# Methyl-ML

Machine learning subcomponent for MethylScan.

Similar to Methyl-clus and Methyl-class, Methyl-ML can be used to perform clustering and classification using usual ML algorithms.

## `onehot.cpp` and `bulk.cpp`

Prepare input data (feature vectors as numpy array files) for other scripts.

## `classify_reads.py`

Classifies the output of `bulk.cpp`.

## `cluster.py`

Detects clusters from the output of `onehot.cpp`.

## `cosine_distance_matrix.py`

Generates, plots, and saves the cosine distance matrix between all samples.

## `dendrogram.py`

Plots the dendrogram of the clustering from `cluster.py`.

## `knn_graph.py`

Plots the knn graph of the data using the distance matrix saved by `cosine_distance_matrix.py`.

## `visualize_clusters_2d.py`

Plots the clusters generated by `cluster.py` in 2D (using PCA, t-SNE, or UMAP).
