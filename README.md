# MethylScan

methyl_clus

# Description
Takes in a file of fasta and generates a Bloom filter of all the k-mers where the middle base is a methylated C or an unmethylated C with a G afterwards. These are inserted into a lvl 0 Bloom filter. Methylated k-mers are then inserted into a lvl 1 Bloom filter.
Distance between any pair of Bloom filters is generated by comparing the intersection of k-mers methylated C over the intersection of all kmer with CpG in the middle.

# Usage
'''
methyl-clus -i test.fa -j test.fa -t 48
'''
-j is a legacy variable that I didn't remove. Functionally does nothing. -i is a file containing path to fasta and -t is the number of threads. Currently file name convention is hardcoded in order to help evaluate accuracy of clustering. 
In practice, the file name format will not matter.


methyl_class

# Description
Takes in a file of fasta and generates a cascading Bloom filter of all the k-mers where the middle base is a methylated C or an unmethylated C with a G afterwards based on the name of the file. 
Takes in another file of fasta and queries each read against the different Bloom filters. The two best are compared using a T test

# Usage
'''
methyl-class  -i test.fa -j ../test2.fa  -t 48
'''
